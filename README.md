# 🚀 CareerAI – AI-Powered Interview & Career Preparation Platform

A production-ready, full-stack SaaS application for AI-powered career preparation. Built with Node.js, Express, MongoDB, and Google Gemini AI.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🤖 AI Mock Interviews | Conversational interviews with Gemini AI, adaptive questions across 9+ roles |
| 📄 Resume Analyzer | PDF/DOCX upload, ATS scoring, keyword analysis, AI suggestions |
| 🗺️ Career Roadmap | Personalized 6-month learning plans generated by Gemini |
| 🎯 Skill Gap Analyzer | Identify missing skills with priorities and timelines |
| 📊 Analytics Dashboard | Charts, radar graphs, heatmaps, performance trends |
| 🤖 AI Mentor (FAB) | Global floating chat assistant on every page |
| 📚 Question Bank | AI-generated interview questions by category + difficulty |
| 🏆 Achievement System | Badges, XP, streaks, career levels |
| ✏️ Resume Builder | Form-based builder with PDF download |
| 🔐 JWT Auth | Secure register/login with demo mode fallback |

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JS, Chart.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (optional — falls back to demo mode)
- **AI:** Google Gemini 1.5 Flash (free tier)
- **Auth:** JWT with bcryptjs
- **File Parsing:** pdf-parse, mammoth (DOCX)

## 🚀 Quick Start

### 1. Clone & Install

```bash
git clone <your-repo>
cd careerai
npm install
```

### 2. Configure Environment

```bash
cp .env.example .env
```

Edit `.env`:

```env
PORT=5000
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/careerai
JWT_SECRET=your_super_secret_key_here
GEMINI_API_KEY=your_gemini_api_key_here
NODE_ENV=production
```

### 3. Get Free API Keys

**Google Gemini API (Free):**
1. Go to → https://aistudio.google.com/app/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy to `.env` as `GEMINI_API_KEY`

**MongoDB Atlas (Free Tier):**
1. Go to → https://www.mongodb.com/atlas
2. Create free M0 cluster
3. Get connection string → paste as `MONGODB_URI`

> ⚠️ **Demo Mode:** The app works without any API keys! Login with `demo@careerai.com` + any password. AI responses will use intelligent fallbacks.

### 4. Run

```bash
# Development
npm run dev

# Production
npm start
```

Open → http://localhost:5000
